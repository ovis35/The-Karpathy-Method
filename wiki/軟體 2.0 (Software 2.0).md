# 軟體 2.0 (Software 2.0)

[[Andrej Karpathy]] 於 2017 年提出的核心論述：神經網路正在成為新的程式設計範式。

## 核心論點

傳統軟體（Software 1.0）由人類工程師明確撰寫程式碼。Software 2.0 則是由人類提供資料集與目標函數，由神經網路「學習」出程式邏輯。這不僅是工具的更替，而是根本性的範式轉移。

Karpathy 觀察到，在許多領域中，神經網路寫出的「程式」已經比人類手寫的更好：
- 影像辨識
- 語音辨識
- 機器翻譯
- 遊戲策略

## 與其他主題的連結

### → Tesla 實踐

Karpathy 在 Tesla 的工作可視為 Software 2.0 理念的大規模實踐——用神經網路取代傳統規則式的自動駕駛演算法。見 [[自動駕駛與 Tesla AI]]。

### → LLM 時代的延伸

大型語言模型（LLM）可視為 Software 2.0 論述的進一步驗證：程式碼生成、推理、規劃等傳統上由人類程式設計師處理的任務，正被神經網路取代。見 [[大型語言模型 (Large Language Models)]]。

### → 工程文化影響

Software 2.0 的概念影響了整個 AI 工程文化，促使業界重新思考：
- 資料集管理的重要性（資料 = 程式碼）
- 模型訓練流程的工程化
- AI 系統的測試與驗證方式

> 注：上述影響分析為 Claude Code 基於公開討論的整理，非 Karpathy 本人逐項陳述。
