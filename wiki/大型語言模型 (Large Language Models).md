# 大型語言模型 (Large Language Models)

[[Andrej Karpathy]] 對大型語言模型的觀點、教育內容與實務分享。

## 概述

Karpathy 雖非 LLM 的直接發明者，但他在 OpenAI 的早期工作經歷、對 GPT 系列的深入理解，以及近年大量的公開教育內容，使他成為 LLM 領域最重要的公共知識傳播者之一。

## 核心教育內容

### YouTube 影片

- **Deep Dive into LLMs like ChatGPT**
  - 深入解析 LLM 的訓練流程、tokenization、RLHF 等核心機制
  - https://www.youtube.com/watch?v=7xTGNNLPyMI

- **How I use LLMs**
  - 個人實務分享：如何在日常工作中有效使用 LLM
  - https://www.youtube.com/watch?v=EWvNQjAaOHw

- **Intro to Large Language Models**
  - LLM 入門概覽，面向一般觀眾
  - https://www.youtube.com/watch?v=zjkBMFhNj_g

### 演講

- **State of GPT** @ Microsoft Build（2023）
  - 系統性解析 GPT 的訓練階段（pretraining → SFT → RLHF）
  - 被廣泛視為理解 LLM 訓練流程的最佳入門演講之一
  - https://www.youtube.com/watch?v=bZQun8Y4L2A

詳見 [[演講與訪談目錄 (Talks and Interviews)]]。

## OpenAI 經歷

Karpathy 於 2015–2017 年在 OpenAI 擔任 Research Scientist。雖然這段時期早於 GPT 系列的主要突破，但他在 OpenAI 的工作（包括 PixelCNN++、World of Bits 等）為後續發展提供了基礎。

見 [[職涯時間線 (Career Timeline)]]。

## 與 Software 2.0 的延伸

LLM 可視為 [[軟體 2.0 (Software 2.0)]] 論述的進一步驗證。Software 2.0 預言神經網路將取代手寫程式碼；LLM 不僅做到了這一點，甚至能直接生成 Software 1.0 的程式碼。

## Zero to Hero 系列中的語言模型

Neural Networks: Zero to Hero 系列的後半段逐步建構語言模型，從字元級 bigram 到完整的 GPT 架構，展示 LLM 的核心原理。見 [[深度學習教育 (Deep Learning Education)]]。
