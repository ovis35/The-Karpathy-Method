# 深度學習教育 (Deep Learning Education)

[[Andrej Karpathy]] 在深度學習教育領域的貢獻與方法論。

## 概述

Karpathy 是當代最有影響力的深度學習教育者之一。他的教學涵蓋從學術課程到 YouTube 影片、從開源專案到部落格文章，形成了一套完整的教育體系。其核心方法論是 **from scratch**——從零開始手寫實作，讓學習者真正理解底層原理，而非僅使用高階框架。

## CS 231n: Convolutional Neural Networks for Visual Recognition

Karpathy 在 Stanford 博士期間與 Fei-Fei Li 共同創建的課程，是全球最受歡迎的深度學習入門課程之一。

- 首次開設：2015
- 課程網站：http://cs231n.stanford.edu/
- 影片：https://www.youtube.com/playlist?list=PLkt2uSq6rBVctENoVBg1TpCC7OQi31AlC
- 課程筆記：https://cs231n.github.io/

CS 231n 的特色在於其高品質的課程筆記與作業設計，讓全球學習者即使無法到 Stanford 上課也能自學。

## Neural Networks: Zero to Hero

Karpathy 離開 Tesla 後推出的 YouTube 教學系列，從最基礎的反向傳播開始，逐步建構到完整的語言模型。

- 播放清單：https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ

### 配套開源專案

- **micrograd**：微型自動微分引擎，用 ~100 行 Python 展示反向傳播核心機制
- **makemore**：字元級語言模型，從 bigram 到 transformer
- **nanoGPT**：最小可訓練的 GPT 實作

這些專案的共通特色是極簡、可讀、教學導向。見 [[開源專案目錄 (Open Source Projects)]]。

## 早期 JavaScript 教學工具

Karpathy 早期製作了一系列瀏覽器端互動工具，降低深度學習的入門門檻：

- **ConvNetJS**：瀏覽器端深度學習
- **REINFORCEjs**：瀏覽器端強化學習
- **recurrentjs**：瀏覽器端 RNN
- **tSNEJS**：瀏覽器端降維視覺化

見 [[開源專案目錄 (Open Source Projects)]]。

## 教學方法論特色

1. **From scratch**：從零手寫，不依賴黑箱框架
2. **漸進式複雜度**：從最簡單的案例開始，逐步增加真實世界的複雜性
3. **程式碼即教材**：開源專案本身就是教學素材
4. **視覺化與互動**：JavaScript 工具讓學習者即時看到結果
5. **跨媒介**：課程影片、部落格文章、GitHub 專案、課程筆記互補
