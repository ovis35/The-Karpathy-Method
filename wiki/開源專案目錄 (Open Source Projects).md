# 開源專案目錄 (Open Source Projects)

[[Andrej Karpathy]] 的開源專案與工具列表。

## 教學用微型實作

這類專案的共通特色是極簡、可讀、教學導向——用最少程式碼展示核心概念。

| 專案 | 說明 | URL |
|------|------|-----|
| **micrograd** | 微型純量自動微分引擎，實作反向傳播。Zero to Hero 系列教材 | https://github.com/karpathy/micrograd |
| **char-rnn** | Torch 字元級語言模型（LSTM/GRU）。催生 RNN 應用熱潮 | https://github.com/karpathy/char-rnn |
| **Minimal RNN gist** | 最小 RNN 實作（~100 行 Python） | https://gist.github.com/karpathy/d4dee566867f8291f086 |

相關：[[深度學習教育 (Deep Learning Education)]]、[[神經網路訓練實務 (Neural Network Training)]]

## JavaScript 深度學習工具

Karpathy 早期製作了一系列瀏覽器端的深度學習工具，讓使用者無需安裝即可互動式學習。

| 專案 | 說明 | URL |
|------|------|-----|
| **ConvNetJS** | JavaScript 深度學習函式庫 | https://cs.stanford.edu/people/karpathy/convnetjs/ |
| **tSNEJS** | JavaScript t-SNE 實作 | https://github.com/karpathy/tsnejs |
| **REINFORCEjs** | JavaScript 強化學習 | https://github.com/karpathy/reinforcejs |
| **recurrentjs** | JavaScript 遞迴神經網路 | https://github.com/karpathy/recurrentjs |
| **GANs in JS** | JavaScript 生成對抗網路 | https://cs.stanford.edu/people/karpathy/gan/ |
